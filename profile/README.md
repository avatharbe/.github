# Avathar

Open-source phpBB extensions and styles built for gaming guild communities.

- [Avathar.be Forum Community](https://www.avathar.be/forum) — support, releases, and development discussions
- [Live demo](https://www.avathar.be/demoforum/app.php/guild) — explore bbGuild on a demo board
- [Project board](https://github.com/orgs/avatharbe/projects/1) — follow development and issue tracking

---

## bbGuild — guild management for phpBB

Want to see it in action? Visit the [live demo board](https://www.avathar.be/demoforum/app.php/guild).

| Repository | Description |
|------------|-------------|
| [bbGuild](https://github.com/avatharbe/bbguild) | Guild management for phpBB, including rosters, portals, and multi-game support |
| [bbDKP](https://github.com/avatharbe/bbDKP) | DKP point management for raid loot distribution (in development) |
| [bbAccounts](https://github.com/avatharbe/bbAccounts) | Double-entry accounting for phpBB, designed for guild banks and raid funds |

### Game extensions

bbGuild supports multiple games through dedicated extensions built on a shared architecture:

| Game | Repository and features |
|------|-------------------------|
| World of Warcraft | [bbguildwow](https://github.com/avatharbe/bbguildwow) — supports Retail, Classic, private servers, and Battle.net API integration |
| Star Wars: The Old Republic | [bbguildswtor](https://github.com/avatharbe/bbguildswtor) |
| Final Fantasy XIV | [bbguildffxiv](https://github.com/avatharbe/bbguildffxiv) |
| Final Fantasy XI | [bbguildffxi](https://github.com/avatharbe/bbguildffxi) |
| Guild Wars 2 | [bbguildgw2](https://github.com/avatharbe/bbguildgw2) |
| The Lord of the Rings Online | [bbguildlotro](https://github.com/avatharbe/bbguildlotro) |
| EverQuest | [bbguildeq](https://github.com/avatharbe/bbguildeq) |
| EverQuest II | [bbguildeq2](https://github.com/avatharbe/bbguildeq2) |
| Lineage II | [bbguildlineage2](https://github.com/avatharbe/bbguildlineage2) |

## Extensions

### Posting and content

| Extension | Description |
|-----------|-------------|
| [PostLove](https://github.com/avatharbe/postlove) | Adds post reactions and likes |
| [QuickReply](https://github.com/avatharbe/QuickReply) | Adds BBCode controls and smilies to the quick-reply editor |
| [bbTips](https://github.com/avatharbe/bbTips) | Adds Wowhead-style BBCode tooltips for item and spell links |
| [badge](https://github.com/avatharbe/badge) | Adds concise, consistent shields.io badges to forum posts |

### Users, ranks, and rewards

| Extension | Description |
|-----------|-------------|
| [RankPostStyling](https://github.com/avatharbe/RankPostStyling) | Assigns a CSS class to each special rank, making posts, search results, and profiles customisable with colours, backgrounds, and images |
| [bbPoints](https://github.com/avatharbe/bbPoints) | Adds a board-wide points economy to phpBB 3.3 |
| [bbPatreon](https://github.com/avatharbe/bbPatreon) | Integrates Patreon supporter recognition with your board |

### Navigation and interface

| Extension | Description |
|-----------|-------------|
| [RecentTopics](https://github.com/avatharbe/RecentTopics) | Displays recent topics on your phpBB board |
| [BreadcrumbMenu](https://github.com/avatharbe/BreadcrumbMenu) | Turns breadcrumb navigation into a forum-tree menu |
| [QuickLogin](https://github.com/avatharbe/QuickLogin) | Adds a simple quick-login lightbox |
| [QuickStyle](https://github.com/avatharbe/QuickStyle) | Lets visitors quickly switch between board styles |
| [pbWoWext](https://github.com/avatharbe/pbwowext) | Adds functionality to the PBWoW 3 style |
